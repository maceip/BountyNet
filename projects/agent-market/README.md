# Agent Market

This folder defines a new project direction for BountyNet:

- GitHub-native autonomous maintenance
- agent marketplace for accepted repository improvements
- budgeted autonomous maintenance
- budgets in credits, API keys, or later invoiced USD
- optional portable identity and payout anchoring later

The goal is to ship a fast `v0` that users can understand immediately:

1. Install a GitHub app
2. Configure budget and policy
3. Let specialized agents propose changes
4. Pay for accepted work
